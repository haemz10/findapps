# Sleepy Koala 앰비언트 사운드 파일

이 폴더에 아래 파일명으로 오디오를 넣으면, 앱이 **자동으로 그 파일을 재생**합니다.
파일이 없으면 앱이 실시간 합성음으로 대체합니다.

| 사운드 | 넣을 파일명 |
|--------|------------|
| 비 | `rain.mp3` |
| 파도 | `waves.mp3` |
| 바람 | `wind.mp3` |
| 모닥불 | `fire.mp3` |

## 형식
- 권장: `.mp3` (또는 `.ogg`, `.wav`, `.m4a` 도 인식)
- 자연스럽게 반복되도록 **루프(loop) 편집된 파일**을 권장합니다(끊김 없이 이어지는 구간).
- 저작권: 반드시 **본인이 권리를 가졌거나 로열티 프리/CC0** 인 파일을 사용하세요.

## 적용 방법
파일을 이 폴더(`apps/sleepy-koala/sounds/`)에 추가하고 커밋/푸시하면 끝입니다.
앱을 새로고침하면 각 버튼 우측 상단에 "파일" 표시가 뜨고, 해당 파일이 재생됩니다.

> 명상 뇌파(델타/세타/알파 바이노럴 비트, 432Hz)는 파일이 필요 없으며 앱이 직접 생성합니다.
