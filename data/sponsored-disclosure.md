# sponsored-disclosure.md — 협찬 표기 문구 (공정위 표시광고법)

> **절대규칙 3-1**: 협찬/체험단이면 **생략 불가**. `/write`마다 확인.
> 아래 문구를 **글 상단 첫 text 블록**에 넣는다(quote 아닌 일반 text).
> 업체가 지정한 문구가 있으면 그것이 **우선**한다.
> "내돈내산"·"광고 아님" 같은 **거짓 부인은 위법** — 협찬 글에 쓰지 않는다.

## 표기 3요소 (2020 개정 심사지침 기준)
1. **경제적 대가가 있었다는 사실**을 명확히
2. **누구(업체명)** 로부터
3. **무엇(제품/서비스/원고료 등)** 을 받았는지

문구는 **본문 첫머리에, 잘 보이게**(글자색·크기로 숨기지 않기). 해시태그로만 표기하는 것은 불충분.

## 대가 유형별 예시 문구

### 제품/서비스 무상 제공 (체험단)
```
이 글은 ○○○로부터 [제품/서비스]을(를) 무상으로 제공받아 작성한 후기입니다.
```

### 원고료/수수료 등 금전 지급
```
이 글은 ○○○로부터 원고료를 지급받고 작성한 광고입니다.
```

### 제품 제공 + 원고료 동시
```
이 글은 ○○○로부터 [제품/서비스] 및 원고료를 지급받아 작성했습니다.
```

### 어학앱/음원 서비스 제휴 (이 블로그에서 있을 법한 케이스)
```
이 글은 ○○○(어학앱/음원 서비스)와 제휴하여 작성되었으며, 소정의 대가를 받았습니다.
```

## 체크
- [ ] 첫 블록에 위치했는가
- [ ] 업체명·대가 유형이 구체적인가
- [ ] 거짓 부인 표현이 없는가
- [ ] (임시저장 후) 육안으로 표기 확인
