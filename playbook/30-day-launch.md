## 랜딩 배포법 (택1, 전부 무료)

**Vercel (가장 쉬움):**
1. https://vercel.com 가입 → "Add New Project" → 이 GitHub 레포 연결
2. Root Directory를 `landing`으로 지정 → Deploy
3. 몇 초 뒤 `https://your-project.vercel.app` 생성

**GitHub Pages:**
1. 레포 Settings → Pages → Source: 이 브랜치, 폴더 `/landing`(또는 루트로 index 이동)
2. 저장 후 `https://<유저>.github.io/findapps/` 접속

**Netlify:** 사이트 새로 만들기 → 레포 연결 → Publish directory `landing` → Deploy.
