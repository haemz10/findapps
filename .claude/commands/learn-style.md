# /learn-style — 스타일 학습 (사용자 제공 글 전용)

**절대규칙 5**: 웹을 임의로 긁지 않는다. **사용자가 이 대화에 붙여넣은 글**로만 학습한다.
(네이버 블로그 본문은 이 환경에서 WebFetch 불가 → 사용자에게 붙여넣기 요청.)

## 순서
1. 사용자가 붙여넣은 글이 없으면 요청한다: "학습할 글 1~2개 전문을 붙여넣어 주세요(제목·소제목·줄바꿈·반말/존댓말 전환 지점·이모지·CTA 문구 포함)."
2. 붙여넣은 글에서 추출한다:
   - 제목 패턴, 태그 패턴
   - 8단 구조 준수 여부와 변형
   - 도입/마무리 톤, 가사 해석의 반말↔존댓말 전환 규칙
   - 인라인 영어 표현 노트 형식과 빈도
   - 인용구 사용, 이모지·기호 빈도
   - 고정 꼬리말(저작권·CTA·사인오프) 문구
3. `data/style-profile.md`를 갱신한다(기존 내용을 지우지 말고 관찰을 누적/정교화). 새로 확정된 사실만 반영.
4. 무엇을 어떻게 바꿨는지 사용자에게 요약 보고.
