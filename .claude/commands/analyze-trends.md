# /analyze-trends — 트렌드 정리 (사용자 제공 자료 전용)

**절대규칙 5**: 임의 웹 수집 금지. **사용자가 붙여넣거나 지정한 자료**로만 갱신한다.

## 순서
1. 자료가 없으면 요청: "정리할 자료를 붙여넣어 주세요 — 예: 요즘 인기 팝송 리스트, 신곡, 검색이 늘 것 같은 키워드/상황, 시즌 이슈 등."
2. 자료에서 다음을 뽑아 `data/trends.md`에 정리:
   - 다룰 만한 곡/아티스트 후보와 이유
   - 유망 키워드 축(곡별 / 큐레이션·상황 / 학습 주제)
   - 시즌·이벤트 훅(예: 발렌타인 러브송, 연말 팝송 등)
3. 근거 없는 추정은 넣지 않는다(지어내기 금지). 확실한 것만.
4. 갱신 내용을 사용자에게 요약 보고.
