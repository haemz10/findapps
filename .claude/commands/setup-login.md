# /setup-login — 최초 1회 로그인 세션 만들기

브라우저 자동화가 매번 로그인하지 않도록, **persistentContext**(`naver-profile/`)에 로그인 상태를 저장한다.
**비밀번호는 저장하지 않는다** — 사용자가 브라우저에서 직접 1회 로그인한다.

## 순서
1. 실행:
   ```bash
   node scripts/naver_login.js
   ```
2. 열리는 크롬 창에서 **사용자가 직접** 네이버에 로그인한다(2단계 인증·캡차 포함). 자동 입력하지 않는다.
3. 로그인 후 블로그 글쓰기 화면까지 진입되면, 안내대로 터미널에서 Enter를 눌러 세션을 저장하고 종료.
4. 이후 `/write`의 임시저장 단계는 이 세션을 재사용한다.

## 주의
- `naver-profile/` 폴더는 로그인 세션이므로 **외부 공유 금지**(.gitignore에 포함됨).
- 세션이 만료되면 이 명령을 다시 실행한다.
- 원격/헤드리스 환경에서는 브라우저 창을 띄울 수 없어 로그인이 불가할 수 있다 → 로컬(데스크톱)에서 실행한다.
