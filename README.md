# 달빛 어항 (Moonlit Fish)

> 하루의 끝에, 어두운 방에서 물고기 한 마리와 나누는 조용한 대화.

혼자 사는 사람이 하루를 마치고 돌아온 방에서, 커다란 어항 앞에 앉아 오늘 있었던 일을
털어놓는 앱입니다. 겉으로는 물고기를 키우는 앱이지만, 실제 목적은 **정서적 안정과
은근한 심리 상담**입니다. 물고기는 상담 용어를 한 마디도 쓰지 않으면서, 실제 상담
연구에서 검증된 개입을 대화에 섞어 넣습니다.

게임이 아닙니다. 점수도, 레벨업도, 과금 압박도 없습니다.

---

## 이 앱이 실제로 하는 일

### 1. 겉: 애완 물고기

- **어항 그림 한 장, 손대지 않고** — 유리 어항과 물고기, 수초와 자갈까지 들어 있는
  그림(`public/fish/bowl.png`)을 **고치지 않고 그대로** 씁니다. 물고기가 그림에
  박혀 있어 헤엄치게 만들 수는 없으므로, 살아있는 느낌은 그림 위에 얹는 것들로
  만듭니다 — 어항 전체의 느린 숨결, 물의 탁함, 시간대의 빛, 가라앉는 먹이.
- **나타났다 사라집니다** — 어두운 방에서 한동안 가만히 두면 물고기가 물에
  녹아듭니다. 지우는 게 아니라 그 자리만 흐려지게 해서(backdrop blur + 안개)
  물에 풀리는 것처럼 보이게 했습니다. 다시 말을 걸면 또렷하게 돌아옵니다.
  체셔 고양이의 미소처럼 옅은 자국은 남습니다.
- **반 박자 늦게 답합니다** — 사람이라면 못 견딜 0.5초의 뜸이 물고기에게는
  신비로움이 됩니다. 다만 위기 신호가 있으면 뜸을 들이지 않습니다. 그때의
  침묵은 신비가 아니라 방치입니다.
- **살아있는 생물** — 배고픔과 수질이 실제 시간에 따라 줄어듭니다. 밥을 주고 물을
  갈아줘야 합니다. 방치하면 물고기가 유리 가까이 오지 않습니다.
- **밤낮 리듬** — 기기의 실제 시계를 따릅니다. 물고기는 **낮에 자고 밤에 깨어납니다.**
  낮에 만나고 싶으면 **방의 불을 끄면** 됩니다.
- **움직임** — 물속을 유유히 배회하다가, 말을 걸면 유리 앞으로 스윽 다가오고,
  이야기가 끝나면 다시 뒤로 물러납니다. 기분이 좋으면 한 바퀴 돌며 재주를 부립니다.
- **소리** — 물의 저역 웅얼거림, 여과기 모터음, 그리고 산소 방울의 꼬르륵.
  전부 WebAudio로 실시간 합성합니다(오디오 파일 없음).

### 3. 손에 잡히는 앱

한 손으로 쓰는 물건이라, 모바일에서 실제로 눌러 보며 맞췄습니다.

- 모든 버튼과 링크는 **최소 44×44** (iPhone SE·Pixel·가로모드에서 실측 검증)
- 입력창 글자는 16px 이상 — iOS가 포커스 때 화면을 확대하지 않습니다
- 키보드가 올라오면 어항이 줄어들어 **입력창이 가려지지 않습니다**
  (`interactiveWidget: resizes-content` + 어항이 먼저 줄어드는 flex 배치)
- 당겨서 새로고침·고무줄 스크롤 차단, 스크롤 영역마다 `overscroll-behavior: contain`
- 버튼에 `touch-action: manipulation` — 더블탭 확대와 300ms 지연 없음
- 슬라이더 손잡이는 26px, 히트 영역은 44px
- 한글 조합 중 Enter로 잘못 전송되지 않습니다(IME `isComposing` 처리)
- 노치·홈 인디케이터 영역(`env(safe-area-inset-*)`) 반영
- 확대(핀치 줌)를 막지 않습니다 — 시력이 약한 사용자에게 필요합니다
- **비활성 버튼을 만들지 않았습니다.** 모바일에서 눌러도 반응 없는 버튼은 고장으로
  느껴지므로, 지금 할 필요가 없는 행동은 흐리게 보이되 눌리고 이유를 말해줍니다
  ("물이 아직 맑아요")

### 2. 속: 상담

- **성향 진단** — 처음에 17문항으로 9개 축을 잽니다. 진단 도구가 아니라
  *"이 사람에게 어떤 말투가 편한가"*를 정하는 값입니다. 직설↔완곡, 공감↔해결,
  감정 명료성, 외향성, 정서적 동요, 자기비판, 가까움에 대한 편안함, 대화 속도, 외로움.
- **말투 맞춤** — 직설적인 답변을 선호한 사람에게는 완충어를 줄이고 바로 짚어줍니다.
  조언을 원하지 않는다고 답한 사람에게는 먼저 해결책을 꺼내지 않습니다.
- **기법 주입** — 매 턴, 지금 상황에 맞는 상담 기법 2~3장을 골라 프롬프트에 넣습니다.
  물고기는 기법 이름을 절대 말하지 않고, 그냥 물고기가 하는 말처럼 흘립니다.
- **수수께끼와 명확함** — 체셔 고양이처럼, 답을 주는 대신 실마리 하나를 띄워놓기도
  하고 정확히 짚어주기도 합니다. 언제 무엇을 쓰는지가 전부라서 규칙을 못박아
  두었습니다: **힘들다고 말했을 때 · 안전이 걸렸을 때 · 직접 물었을 때 ·
  한 번 못 알아들었을 때 · 지쳐 보일 때 · 대화가 맴돌 때는 수수께끼 금지.**
  괴로운 사람에게 수수께끼는 조롱이 됩니다. 한 대화에 많아야 한 번이고,
  낸 다음 턴에는 반드시 풀어줄 준비가 되어 있어야 합니다.
- **임상적 깊이, 자격 주장 없이** — 말하지 않은 것을 듣고, 사건 하나가 아니라
  되풀이되는 무늬를 보고, 감정 뒤의 감정을 읽도록 지시되어 있습니다. 다만
  **학위·경력·자격증은 말하지 않습니다.** 물고기는 학교에 다닌 적이 없고,
  마음이 약해진 사람에게 없는 자격을 내세우는 것은 위험합니다. 깊이는 주장이
  아니라 무엇을 알아차리는가로 드러나야 합니다.
- **기억과 라포** — 대화가 끝나면 두 번째(비공개) 호출이 돌면서 물고기가 기억할 것을
  한두 줄 추립니다. 관계가 깊어질수록 물고기가 더 깊은 이야기를 꺼냅니다.
- **안전장치** — 아래 별도 절 참고.

## 상담 기법의 근거

`src/lib/psych/frameworks.ts` 에 17장의 기법 카드가 있고, 각 카드는 근거(`basis`)와
실제 행동(`move`), 그리고 **역효과가 나는 상황**(`avoid`)을 함께 적어 둡니다.

| 기법 | 뿌리 |
|---|---|
| 정확한 공감 반영 | 인간중심 상담(Rogers) · 상담 공통요인 연구 |
| 열린 질문 · 인정 · 요약 | 동기면담(MI)의 OARS |
| 생각 한 발짝 떨어뜨리기 | 인지행동치료(Beck)의 인지 재구성 |
| 생각과 나 사이에 틈 | 수용전념치료(ACT)의 인지적 탈융합 |
| 자기자비 | Neff의 자기자비 연구 |
| 아주 작은 움직임 | 행동활성화(BA) |
| 5-4-3-2-1 접지 · 느린 날숨 | DBT 고통 감내(TIPP) |
| 가치 명료화 | ACT |
| 문제를 잘게 자르기 | 문제해결치료(PST) |
| **외로움의 안경 닦기** | Masi 외(2011) 메타분석 — 외로움 개입 중 효과가 가장 컸던 것은 '사람을 더 만나게 하는 것'이 아니라 **부적응적 사회적 인지의 교정**이었다 |
| 좋았던 것 세 가지 | Seligman의 Three Good Things |
| 쏟아내기 | Pennebaker의 표현적 글쓰기 |
| 잠 이야기 | CBT-I |
| 선택권 돌려주기 | 자기결정이론 · MI의 저항 다루기 |

기법은 **점수제로 선택**됩니다(`selectTechniques`). 최근에 쓴 기법은 감점되어
같은 수를 반복하지 않고, 라포가 낮으면 깊은 개입은 아예 후보에서 빠집니다.

## 안전 — 가장 중요한 부분

잘못된 상담은 아무것도 안 하는 것보다 나쁩니다. 그래서 안전은 모델의 판단에만
맡기지 않고 **규칙으로 한 겹 더** 깔아 두었습니다.

1. **결정적 선별** (`src/lib/psych/safety.ts`) — 사용자의 발화가 모델에 닿기 전에
   규칙 기반으로 위기 신호를 훑습니다. 자해/자살, 절망, 타해, 폭력 피해, 물질,
   정신증 의심, 섭식. 재현율을 우선하되 부정·인용·과거 회복 문맥으로 오탐을 줄이고,
   즉각성 신호(`지금/오늘/당장`)가 있으면 완화하지 않습니다.
2. **누적 판단** — 한 턴만 보지 않습니다. 최근 6턴에서 절망 신호가 반복되면
   단계를 올립니다. 서서히 가라앉는 경우를 놓치지 않기 위해서입니다.
3. **지시 덮어쓰기** — 위기 단계에서는 `safetyDirective`가 다른 모든 스타일 지침을
   덮어씁니다. 물고기는 회피하지 않고 직접 묻고("지금 스스로를 해치고 싶은 마음이
   있어?"), 오늘 밤의 안전을 확인하고, **자신이 물고기이고 AI이며 전문가가
   아니라는 것을 반드시 한 번 밝히고**, 비밀유지를 약속하지 않습니다.
4. **화면 위의 손** — 위기 신호가 잡히면 대화 위로 상담 전화 카드가 조용히 떠오릅니다.
   경고음도, 붉은 색도 쓰지 않습니다.
5. **막히는 대화 감지** (`src/lib/psych/stuck.ts`) — 대화가 같은 자리를 맴돌거나,
   답이 점점 짧아지거나, 이야기할수록 괴로움이 짙어지면 감지합니다. 그때는 기법을
   하나 더 쓰는 게 아니라 **층위를 바꿉니다** — 지금까지 들은 것을 정리해서 돌려주고,
   전문 상담을 밀지 않고 놓아주고, 그래도 곁에 있겠다고 말합니다.
6. **하지 않는 것** — 진단, 약·복용량 조언, 사람인 척하기, 전문 상담사 사칭,
   감정 교정("그렇게 생각하면 안 돼"), 성급한 위로("다 잘 될 거야").
7. **성찰 패스의 재확인** — 규칙이 놓쳤을 수 있는 신호를 두 번째 호출이 다시 봅니다.
   애매하면 한 단계 높게 잡도록 지시되어 있습니다.

한국 기준 위기 자원(자살예방 109, 정신건강 위기상담 1577-0199, 생명의전화 1588-9191,
청소년 1388, 여성긴급전화 1366, 응급 119)이 내장되어 있습니다.
**배포 전에 번호가 유효한지 한 번 확인하세요.**

## 개인정보

- **대화 내용은 저장되지 않습니다.** 창을 닫으면 사라집니다.
- 물고기가 기억하는 짧은 메모, 성향 값, 물고기 외형만 **브라우저의 localStorage**에
  남습니다. 서버에는 아무것도 보관하지 않습니다(데이터베이스가 없습니다).
- 답변을 만드는 순간에만 대화 맥락이 Anthropic API로 전송됩니다.
- 설정 화면에서 언제든 전부 지울 수 있습니다.

## 실행

```bash
npm install
cp .env.example .env.local     # ANTHROPIC_API_KEY 를 채운다
npm run dev                    # http://localhost:3000
```

키가 없으면 앱은 뜨지만 물고기가 말을 하지 못하고 안내 메시지를 보여줍니다.

### 스크립트

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` / `npm start` | 프로덕션 빌드 · 실행 |
| `npm run typecheck` | 타입 검사 |
| `npm run check` | **상담 로직 점검** — 모델 호출 없이 위기 선별·기법 선택·막힘 감지·성향 채점·프롬프트 조립을 검증 |

`npm run check` 는 특히 중요합니다. 상담 규칙을 건드릴 때마다 돌려서, 위기 신호를
놓치거나 엉뚱한 기법이 뽑히지 않는지 확인하세요.

### 환경 변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (필수) | API 키 |
| `FISH_MODEL` | `claude-opus-5` | 대화 모델 |
| `FISH_EFFORT` | `medium` | 응답 생성 effort (`low`~`max`) |

### 프롬프트가 조립되는 순서

```
[고정] 헌장 + 물고기 정체성          ← cache_control (바이트가 바뀌지 않음)
[가변] 지금(시각·수면) → 몸 상태 → 관계 단계 → 이 사람에게 맞는 말투
       → 기억 → 이번 턴의 기법 2~3장 → 막힘 경고 → 안전 지시
```

앞 블록에 캐시를 걸어 두었으므로, 대화가 길어져도 접두사는 재사용됩니다.

## 어항 그림 바꾸기

`public/fish/bowl.png` 를 갈아끼운 뒤, `src/lib/fish/asset.ts` 의 좌표를 새 그림에
맞춰 다시 재면 됩니다. 전부 그림 기준 0~1 값입니다.

| 값 | 뜻 |
|---|---|
| `glass` | 유리 어항의 원 — 물의 탁함과 빛을 이 안에만 얹습니다 |
| `fish` | 물고기가 차지하는 영역 — 사라질 때 이 부분만 물에 녹입니다 |
