# 물고기 그림

이 폴더에 물고기 그림 한 장을 넣으면 앱이 그걸로 물고기를 그립니다.

## 넣어야 할 것

```
public/fish/betta.png
```

- **배경이 지워진 PNG** (투명 배경). 수초·조명·말풍선 같은 건 잘려 있어야 합니다.
- 물고기 하나만. 지느러미가 잘리지 않게 여백을 조금 남겨 주세요.
- 권장 크기: 가로 1000~1600px. 어두운 방에서 크게 보이는 화면이라 작으면 뭉개집니다.

파일이 없으면 앱은 예전의 계산으로 그리는 물고기로 자동 대체됩니다
(앱이 깨지지 않도록 남겨 둔 임시 대비책입니다).

## 그림을 바꾼 뒤 할 일

`src/lib/fish/asset.ts` 의 값을 새 그림에 맞춰 다시 잽니다.

| 값 | 뜻 | 재는 법 |
|---|---|---|
| `mouth` | 말풍선이 나올 입 위치 (0~1) | 이미지에서 입의 좌표 ÷ 이미지 크기 |
| `bodyBox` | 몸이 실제로 차지하는 영역 (0~1) | 투명 여백을 뺀 실제 그림 범위 |
| `frontFacing` | 정면을 보는 그림인가 | 정면이면 `true` — 좌우로 뒤집지 않습니다 |
| `aspect` | 가로 ÷ 세로 | |
