# Module 1 — The 30-Prompt Library

Every message a local service business sends, with a proven prompt behind it.
Copy a prompt, replace the `[BRACKETS]`, paste into any AI chatbot, send the reply.

**Reusable header** — paste this once at the top of your chat so every reply sounds like you:
```
You run [BUSINESS NAME], a [TRADE] business in [SUBURB/CITY], Australia.
Your tone: friendly, plain-English, confident, local — never corporate or robotic.
Use Australian spelling. Keep replies short enough to text unless I say otherwise.
Remember this for everything I ask next.
```

---

## A. Winning the enquiry (1–7)

**1. Instant enquiry reply**
```
A customer sent: "[PASTE MESSAGE]". Write a warm reply that shows I understood,
gives a clear next step, and asks the one best question to move toward a booking.
```

**2. Enquiry reply — no price yet**
```
Customer asked for a price on "[JOB]" but I need to see it first. Write a reply that
stays keen, explains why a quick look/call gives an accurate price, and offers 2 time options.
```

**3. After-hours auto-reply**
```
Write a friendly after-hours auto-response for missed enquiries that promises a reply
by [TIME] tomorrow, and for emergencies gives [EMERGENCY NUMBER/INSTRUCTION].
```

**4. Voicemail-to-text follow-up**
```
I missed a call and got this voicemail: "[PASTE/SUMMARISE]". Write a text I can send
right now that references what they said and asks for the best time to talk.
```

**5. "How much do you charge?" opener**
```
Someone messaged just "how much do you charge for [JOB]?". Write a reply that gives a
helpful ballpark range, explains what changes the price, and invites them to book a proper quote.
```

**6. Qualifying questions**
```
Before I quote a "[JOB TYPE]" job, list the 5 most important questions to ask the customer
so my quote is accurate, written as a friendly single message.
```

**7. Turning a price shopper into a booking**
```
Customer is clearly ringing around on price for "[JOB]". Write a reply that competes on
value (reliability, warranty, cleanliness, on-time) without trashing competitors or dropping my rate.
```

---

## B. Quotes & proposals (8–14)

**8. Instant quote draft**
```
Write a professional quote. Job: [DETAILS]. My rate [$X/hr], call-out [$X], materials [$X],
estimated hours [X]. Customer: [NAME]. Include friendly intro, itemised breakdown with AUD
total, what's included/excluded, validity period, and how to accept.
```

**9. Good / Better / Best quote**
```
Turn this job into three options — Good, Better, Best — for "[JOB]". For each: what's included,
rough price [use my numbers: ...], and who it suits. Make the middle option the obvious choice.
```

**10. Explaining a high quote**
```
My quote for "[JOB]" is [$X], which is higher than a cheap competitor. Write a short note that
justifies it with quality, warranty, and doing it once properly — confident, not defensive.
```

**11. Quote cover message (text)**
```
Write a 3-sentence text to send with a quote for "[JOB]" for [NAME] that builds trust and
makes it easy to say yes.
```

**12. Scope change / variation**
```
The job grew: originally "[ORIGINAL]", now also needs "[EXTRA]". Write a clear, fair message
explaining the variation and the added cost [$X] before I proceed.
```

**13. Deposit request**
```
Write a polite message asking [NAME] for a [X%/$X] deposit to lock in their booking for [DATE],
explaining it secures materials and their spot. Include how to pay: [METHOD].
```

**14. Declining a job politely**
```
I can't take "[JOB]" (reason: [too far / not my trade / booked out]). Write a courteous decline
that leaves a good impression and, if possible, points them somewhere helpful.
```

---

## C. Follow-ups & winning back (15–20)

**15. Quote follow-up #1 (3 days)**
```
I quoted "[JOB]" for [NAME] 3 days ago, no reply. Write a friendly, no-pressure nudge that
reminds them of the value and makes it easy to reply. Text and email versions.
```

**16. Quote follow-up #2 (7 days)**
```
Second follow-up for the "[JOB]" quote — still no reply. Write a short message that offers to
answer any questions or adjust the scope, and gently asks if they've gone another way.
```

**17. "Last check-in" close**
```
Final follow-up on the "[JOB]" quote (day 14). Write a respectful "I'll close this off unless
I hear back" message that often gets a reply — warm, not guilt-trippy.
```

**18. Re-engage an old customer**
```
Write a friendly check-in to a past customer, [NAME], I did "[PAST JOB]" for [X months] ago,
offering a seasonal reminder/tune-up for "[RELEVANT SERVICE]".
```

**19. Seasonal offer blast**
```
Write a short broadcast text to past customers offering "[SEASONAL SERVICE/OFFER]" before
[SEASON/DEADLINE]. Upbeat, local, one clear call to action. Give me 2 versions.
```

**20. Cancellation win-back**
```
A customer cancelled their booking for "[JOB]". Write a gracious message that keeps the door
open and offers to rebook when they're ready.
```

---

## D. Reviews & reputation (21–25)

**21. Review request (text)**
```
Write a warm text asking [NAME] for a Google review after I finished "[JOB]". Genuine, easy,
includes a line they could copy as their review. Keep it short.
```

**22. Review request (email)**
```
Same as above but a slightly longer, friendly email version with the review link placeholder [LINK].
```

**23. Reply to a 5-star review**
```
Write a warm, personal public reply to this 5-star review: "[PASTE REVIEW]". Thank them,
mention the job naturally, invite them back.
```

**24. Reply to a negative review**
```
Write a calm, professional public reply to this negative review: "[PASTE REVIEW]". Take the
high road, show I care, move the conversation offline. Never argue.
```

**25. Referral ask**
```
Write a friendly message asking a happy customer, [NAME], if they know anyone else who needs
"[SERVICE]", making it easy and low-pressure to refer me.
```

---

## E. Admin, marketing & the boring stuff (26–30)

**26. Google Business Profile post**
```
Write 3 Google Business Profile posts for my [TRADE] business in [SUBURB]. Current focus:
"[JOB/SEASON/OFFER]". Naturally include service + suburb for local search. Clear call to action.
```

**27. Social media caption pack**
```
I did this job: "[DESCRIBE + before/after]". Write 5 short social captions (Instagram/Facebook)
that show the result, sound local and human, and end with a soft call to action.
```

**28. Invoice reminder**
```
Write a polite reminder for an unpaid invoice: [NAME], invoice [#], amount [$X], due [DATE].
Friendly first-reminder tone. Give me a firmer version too for if it's ignored.
```

**29. Booking confirmation + prep**
```
Write a confirmation message for [NAME]'s booking on [DATE/TIME] for "[JOB]", including what
they should do to prepare and how to reach me.
```

**30. FAQ / auto-answer builder**
```
List the 10 questions customers most often ask a [TRADE] business, with a short, friendly,
on-brand answer for each — so I can paste them into an auto-responder or website.
```
