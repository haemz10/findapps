# 상품 제작 틀 (L1 · L2 · L3)

> AI로 제작하는 것을 전제로 한 "빈칸 채우기" 틀입니다.
> 니치를 `{{니치}}`, 타깃 고객을 `{{고객}}`, 그들의 핵심 반복업무를 `{{반복업무}}`로 두고 채우세요.

---

## L1 — 무료(또는 $19) 미끼 상품 · 하루 제작

**목적**: 이메일 수집 + 신뢰 확보. 완성도보다 "즉시 쓸모"가 중요.

**형태 후보** (하나만):
- `{{니치}} AI 프롬프트 팩` — 바로 복붙하는 프롬프트 15~30개 (PDF/Notion)
- `{{반복업무}} 자동화 템플릿` — Make/Zapier/n8n 시나리오 파일 + 설명
- `{{고객}}용 체크리스트 + 스와이프 파일`

**AI 제작 방법**: Claude에게 "{{고객}}이 {{반복업무}}에 쓸 수 있는 검증된 프롬프트 20개를, 각각 사용상황·프롬프트·예시 출력 형식으로" 요청 → 다듬어 PDF/Notion으로.

**전달**: Gumroad에 $0 상품으로 등록(이메일 필수 입력) 또는 이메일 툴의 자동응답에 첨부.

---

## L2 — 핵심 상품 $49~$99 · 2~3일 제작

**목적**: 주 매출의 절반. "직접 하면 20시간, 이걸 쓰면 20분" 가치 제안.

**구성 (풀 키트):**
1. **템플릿/자동화 자산** — 실제로 돌아가는 워크플로우 파일, 프롬프트 라이브러리, 스프레드시트
2. **셋업 영상** — 5~10분 화면 녹화(따라만 하면 세팅 완료). *이 환경 Higgsfield MCP로 나레이션 영상 제작 가능*
3. **SOP 문서** — 매주 어떻게 운영/자동화하는지 단계별 가이드
4. **보너스** — 자주 쓰는 변형 프롬프트, 트러블슈팅 FAQ

**가격 근거**: 절약 시간 × 고객 시급으로 정당화. $59면 커피 몇 잔 값에 "매달 20시간 절약".

**AI 제작 순서**:
1. Claude로 상품 커리큘럼/목차 생성
2. 각 모듈의 템플릿·프롬프트를 Claude로 생성 후 실제 검증(반드시 한 번은 직접 돌려볼 것)
3. 영상 스크립트 Claude 생성 → Higgsfield로 영상화 또는 직접 화면녹화
4. Gumroad에 $59로 등록, L1 구매자에게 자동 이메일로 안내

## L3 — 수익 견인: 서비스 또는 구독 $290~$490/월

소수 고객으로 큰 금액을 채우는 계층. 둘 중 하나 선택.

### 옵션 A — 셋업 대행 (Productized Service)
- "당신 사업에 {{반복업무}} 자동화를 **72시간 안에 설치**해 드립니다" — 고정가 패키지 $490.
- 실제 작업의 80%는 L2 자산 재사용 → 건당 2~3시간.
- 3~6명만 확보하면 $1,500~$2,900/월.

### 옵션 B — 유료 구독 커뮤니티/뉴스레터
- 월 $25 — 매주 새 프롬프트·자동화 레시피 + Q&A.
- 콘텐츠는 이미 만드는 §4 엔진에서 프리미엄 편만 분리.
- 120명이면 $3,000/월 (이탈률 관리 필요).

**권장**: 초기엔 **A(서비스)** 로 현금 흐름을 빠르게 만들고, 노하우/수요가 쌓이면 **B(구독)** 로 전환해 진짜 패시브화.

---

## 가격/오퍼 원칙
- 항상 **3개 가격 옵션**을 나란히 제시(앵커링). 가운데가 가장 많이 팔리게 설계.
- L2에 **7일 환불 보장** 명시 → 구매 저항 제거, 실제 환불률은 대개 5% 미만.
- 런칭 첫 주는 **얼리버드 30% 할인 + 마감 타이머**로 초기 판매·후기 확보.
